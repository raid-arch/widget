# School Board

Android 8.0以降向け、端末内保存の授業・提出物・予定アプリ。通信権限やGoogleログインは使いません。授業データは初期状態では空です。

## APKを作る

Android SDK 35、JDK 17、Gradle 8.9を用意し、`gradle :app:assembleDebug :app:lintDebug` を実行します。Android Studioではこのフォルダを開いてSDKの場所を設定できます。
APK出力: `app/build/outputs/apk/debug/app-debug.apk`。
GitHubに配置する場合は、Actionsの **Build APK → Run workflow** から同じビルドを実行できます。mainへのpushまたは手動実行でビルドし、リリース公開は行いません。debug APKは試用向けです。継続配布時は同じ署名鍵を保存してrelease署名を設定してください。GitHub Actionsのdebug署名鍵は実行ごとに変わり得るため、更新インストール用途には固定鍵が必要です。

## 使い方

- 提出物は追加・編集・削除・提出済みへの変更に対応。日付順に表示します。
- ホーム画面長押しからSchool Boardウィジェットを追加。標準5×4（実際のセル数はランチャー依存）、サイズ変更可能。提出物・授業・予定を切り替え、最大3件を表示。提出物タップで完了、＋で入力画面に移動できます。編集や全件表示はアプリで行います。
- 初期通知時刻は20:00。設定で変更できます。Android 13以降は通知許可が必要です。未提出件数・最も近い期限と、登録忘れの確認を1日1回通知します。端末の省電力設定で遅れる場合があります。強制停止後はアプリを再度開いてください。
- 設定からJSONを読み込むと、授業・年間予定を一括置換します。提出物は保持します。`sample-school-year.json` が形式見本です。曜日は月=1〜日=7、`from`/`to` は授業の適用期間（両端を含む）です。休講日は現版では自動除外しません。
- 今後このチャットに新しい時間割・年間予定を渡せば、取り込み用JSONを作成できます。チャットから端末への自動配信はありません。

## データ

提出物・取り込んだ予定はアプリ専用領域に保存。バックアップは無効のため、アンインストール・データ消去で削除されます。GitHubに個人の予定や秘密情報をコミットしないでください。

## 確認状況

この環境ではAndroid SDKとGradleが未導入で、SDK取得もプロキシへの接続エラーとなったため、APKビルド・Android Lint・実機動作は未確認です。XML整形式の静的検査のみ実施。
実機では通知許可・再起動後の予約・時刻変更・提出物の編集/完了・ウィジェット操作・不正JSONの拒否と保存データ維持を確認してください。
